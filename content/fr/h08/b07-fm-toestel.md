:::kern
Un appareil FM pour la VHF ou l'UHF a trois réglages importants : la **fréquence**, le **squelch** (silencieux) et le **volume**. Avec le **S-mètre**, vous lisez la force d'un signal reçu. Dans un **report**, vous indiquez avec deux chiffres si vous comprenez bien l'autre station et quelle est sa force. Cela fait partie de l'**épreuve pratique**.
:::

### Les réglages
| Réglage | Que fait-il ? | Comment le régler ? |
|---|---|---|
| **fréquence** (accord) | choisit la fréquence | en FM : de sorte que le signal soit le plus fort sur le S-mètre, ou le plus compréhensible avec le moins de bruit |
| **squelch** (silencieux) | coupe le haut-parleur quand il n'y a pas de signal (ou un signal trop faible) | sans signal : tournez jusqu'à ce que le bruit disparaisse **tout juste**, pas plus loin |
| **volume** | la puissance sonore du haut-parleur | selon votre goût |
| **PTT** (sur le microphone) | émettre | enfoncer pour parler, relâcher pour écouter |

:::valkuil
Squelch trop ouvert : vous entendez du bruit en permanence. Trop fermé : vous n'entendez plus les stations faibles. Donc : **juste** au point où le bruit disparaît.
:::

### Le S-mètre
{{svg:h08-smeter|Le S-mètre va de S1 à S9. Au-dessus, il indique de combien de dB le signal dépasse S9.}}

- L'échelle va de **S1** (très faible) à **S9** (fort).
- Chaque point S en plus signifie **2 × plus de tension** à l'entrée du récepteur.
- De S1 à S9, il y a 8 pas : 2 × 2 × 2 × 2 × 2 × 2 × 2 × 2 = **256**. Un signal S9 a donc **256 fois** la tension de S1.

:::weetje Pas matière d'examen
Au-dessus de S9, l'échelle indique encore « +10 », « +20 » ... C'est le nombre de **dB** au-dessus de S9.
:::

### Le report de signal (deux chiffres)
| 1er chiffre : lisibilité (R) | 2e chiffre : force (S) |
|---|---|
| 1 = pas lisible | 1 = à peine audible |
| 2 = partiellement lisible | 2 = très faible |
| 3 = tout juste lisible | 3 = faible |
| 4 = lisible | 4 = suffisant |
| 5 = bien lisible | 5 = bon |
| | 6 = fort |
| | 7 = très fort au casque, compréhensible au haut-parleur |
| | 8 = bien compréhensible au haut-parleur |
| | 9 = très fort au haut-parleur |

Le 2e chiffre se lit généralement sur le **S-mètre**. « Vous êtes 59 » signifie : bien lisible et S9.

### Exemple résolu
Vous comprenez tout bien et le S-mètre est sur S7. Votre report est **57** (« cinq sept »).

<details class="zelf" markdown="1"><summary>À vous : vous comprenez l'autre tout juste et le S-mètre est sur S3. Quel report ?</summary>

**33** : lisibilité 3 (tout juste lisible), force 3.

</details>
