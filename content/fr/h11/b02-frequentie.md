:::kern
Ces codes portent sur **qui vous êtes**, **où vous êtes** et **sur quelle fréquence** vous travaillez : **QRA**, **QTH**, **QRB**, **QRG**, **QRH** et **QTR**.
:::

| Code | Question (avec ?) | Affirmation (sans ?) |
|---|---|---|
| **QRA** | Quel est votre nom (indicatif) ? | Mon nom est (indicatif) |
| **QTH** | Quelle est votre position ? | Ma position est ... |
| **QRB** | Quelle est la distance entre nous ? | La distance entre nous est de ... km |
| **QRG** | Quelle est la fréquence ? | La fréquence est ... |
| **QRH** | Ma fréquence est-elle constante ? | La fréquence n'est pas constante |
| **QTR** | Quelle est l'heure exacte ? | L'heure exacte est ... |

:::weetje
Officiellement, **QRA** porte sur le **nom de votre station**. En pratique, on le demande pour entendre votre prénom ou votre indicatif. Le manuel le présente comme dans le tableau ci-dessus.
:::

### Un exemple
« ON3BBB, **QTH** ? » signifie : où êtes-vous ? La réponse : « **QTH** Gand ». Et avec « **QRB** ? » vous demandez combien de kilomètres vous séparent.

:::valkuil
- **QTH** = position (où), **QRG** = fréquence, **QRB** = distance. Trois questions différentes.
- **QRH** concerne une fréquence qui **glisse**, donc qui n'est pas stable.
:::

<details class="zelf" markdown="1"><summary>À vous d'essayer : quel code utilisez-vous pour demander la position de quelqu'un ?</summary>

**QTH?** La réponse commence par « mon QTH est ... ».

</details>
