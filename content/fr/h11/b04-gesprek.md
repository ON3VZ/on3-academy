:::kern
Ce sont les codes que vous entendez le plus pendant un QSO : **QRL** (occupé), **QRZ** (qui appelle), **QSL** (accuser réception), **QSY** (autre fréquence), **QRX** (attendez), **QRT** (arrêt), **QRV** (prêt) et quelques autres.
:::

| Code | Question (avec ?) | Affirmation (sans ?) |
|---|---|---|
| **QRL** | Êtes-vous occupé ? | Je suis occupé |
| **QRZ** | Par qui suis-je appelé ? | Vous êtes appelé par ... |
| **QSO** | Pouvez-vous communiquer avec ... ? | Je peux communiquer avec ... |
| **QSL** | Pouvez-vous accuser réception ? | J'accuse réception |
| **QSY** | Dois-je passer à l'émission sur une autre fréquence ? | Je passe à l'émission sur une autre fréquence |
| **QRX** | Quand me rappellerez-vous ? | Je vous rappellerai à ... |
| **QRT** | Dois-je cesser la transmission ? | Je cesse la transmission |
| **QRV** | Êtes-vous prêt à émettre ? | Je suis prêt à émettre |
| **QRY** | Quel est mon tour ? | Votre tour est le numéro ... |
| **QSK** | Pouvez-vous recevoir pendant que vous émettez ? | Je peux recevoir pendant que j'émets |
| **QSP** | Voulez-vous retransmettre à ... ? | Je retransmettrai à ... |
| **QTC** | Avez-vous des messages pour moi ? | J'ai des messages pour vous |
| **QRW** | Dois-je avertir ... que vous l'appelez sur ... ? | Veuillez avertir ... que je l'appelle sur ... |
| **QRQ** | Dois-je transmettre plus vite ? | Transmettez plus vite |
| **QRS** | Dois-je transmettre plus lentement ? | Transmettez plus lentement |

{{svg:h11-gesprek|Une courte conversation dans laquelle vous reconnaissez plusieurs codes Q.}}

### D'abord écouter : QRL?
Avant d'émettre, vous écoutez et vous demandez : « **QRL?** » (la fréquence est-elle occupée ?). Si vous n'entendez rien, vous lancez « CQ ». Ceci rejoint le chapitre Procédures de trafic.

:::valkuil
- **QRL** = je suis **occupé** (la fréquence est occupée). Pas « libre ».
- **QRZ?** demande **qui** vous appelle. **QRX** demande quand vous serez appelé **à nouveau**.
- **QSL** est aussi le nom de la **carte** que les amateurs échangent après un contact pour le confirmer.
:::

<details class="zelf" markdown="1"><summary>À vous d'essayer : vous entendez « QRZ? ». Que veut dire l'autre ?</summary>

Il demande : **par qui suis-je appelé ?** Vous répondez avec votre indicatif d'appel.

</details>
<details class="zelf" markdown="1"><summary>À vous d'essayer : vous voulez passer sur une autre fréquence. Que dites-vous ?</summary>

« **QSY** » suivi de la nouvelle fréquence, par exemple « QSY 14,250 ».

</details>
