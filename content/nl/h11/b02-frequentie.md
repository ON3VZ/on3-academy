:::kern
Deze codes gaan over **wie je bent**, **waar je zit** en **op welke frequentie** je werkt: **QRA**, **QTH**, **QRB**, **QRG**, **QRH** en **QTR**.
:::

| Code | Vraag (met ?) | Mededeling (zonder ?) |
|---|---|---|
| **QRA** | Wat is uw naam (call)? | Mijn naam is (call) |
| **QTH** | Wat is uw locatie? | Mijn locatie is ... |
| **QRB** | Hoe groot is onze afstand? | Onze afstand is ... km |
| **QRG** | Wat is de frequentie? | De frequentie is ... |
| **QRH** | Is mijn frequentie constant? | De frequentie is niet constant |
| **QTR** | Wat is de juiste tijd? | De juiste tijd is ... |

:::weetje
Officieel gaat **QRA** over de **naam van je station**. In de praktijk vraagt men ernaar om je naam of roepnaam te horen. In het handboek staat het zoals in de tabel hierboven.
:::

### Een voorbeeld
"ON3BBB, **QTH**?" betekent: waar zit je? Het antwoord: "**QTH** Gent". En met "**QRB**?" vraag je hoeveel kilometer er tussen jullie ligt.

:::valkuil
- **QTH** = locatie (waar), **QRG** = frequentie, **QRB** = afstand. Drie verschillende vragen.
- **QRH** gaat over een frequentie die **zweeft**, dus niet stabiel is.
:::

<details class="zelf" markdown="1"><summary>Zelf proberen: welke code gebruik je om iemands locatie te vragen?</summary>

**QTH?** Het antwoord begint met "mijn QTH is ...".

</details>
