:::kern
Dit zijn de codes die je het meest tijdens een QSO hoort: **QRL** (bezet), **QRZ** (wie roept), **QSL** (bevestigen), **QSY** (andere frequentie), **QRX** (wacht), **QRT** (stop), **QRV** (klaar) en nog enkele.
:::

| Code | Vraag (met ?) | Mededeling (zonder ?) |
|---|---|---|
| **QRL** | Bent u bezig? | Ik ben bezig |
| **QRZ** | Wie roept mij aan? | U wordt aangeroepen door ... |
| **QSO** | Kunt u werken met ...? | Ik kan werken met ... |
| **QSL** | Wilt u de ontvangst bevestigen? | Ik bevestig de ontvangst |
| **QSY** | Zal ik op een andere frequentie gaan zenden? | Ik ga op een andere frequentie zenden |
| **QRX** | Wanneer roept u mij weer? | Ik zal u weer oproepen om ... |
| **QRT** | Zal ik stoppen met seinen? | Ik stop met seinen |
| **QRV** | Bent u klaar om te zenden? | Ik ben gereed om te zenden |
| **QRY** | Wanneer ben ik aan de beurt? | Uw beurt is nummer ... |
| **QSK** | Kunt u ontvangen tijdens het zenden? | Ik kan ontvangen tijdens het zenden |
| **QSP** | Wilt u doorgeven aan ...? | Ik zal doorgeven aan ... |
| **QTC** | Hebt u berichten voor mij? | Ik heb berichten voor u |
| **QRW** | Zal ik ... meedelen dat u hem op ... roept? | Deel a.u.b. mee dat ik hem op ... roep |
| **QRQ** | Zal ik sneller seinen? | Sein sneller |
| **QRS** | Zal ik langzamer seinen? | Sein langzamer |

{{svg:h11-gesprek|Een kort gesprek waarin je meerdere Q-codes herkent.}}

### Eerst luisteren: QRL?
Voor je zendt, luister je en vraag je: "**QRL?**" (is de frequentie bezet?). Hoor je niets, dan roep je "CQ". Dit sluit aan bij het hoofdstuk Operating procedures.

:::valkuil
- **QRL** = ik ben **bezig** (de frequentie is bezet). Niet "vrij".
- **QRZ?** vraagt **wie** je roept. **QRX** vraagt wanneer je **opnieuw** wordt geroepen.
- **QSL** is ook de naam van de **kaart** die amateurs na een contact uitwisselen als bevestiging.
:::

<details class="zelf" markdown="1"><summary>Zelf proberen: je hoort "QRZ?" Wat bedoelt de ander?</summary>

Hij vraagt: **wie roept mij aan?** Je antwoordt met je roepnaam.

</details>
<details class="zelf" markdown="1"><summary>Zelf proberen: je wilt naar een andere frequentie. Wat zeg je?</summary>

"**QSY**" gevolgd door de nieuwe frequentie, bijvoorbeeld "QSY 14,250".

</details>
